# 考研这条路，我想和你聊聊

> 作者本科金融学专业，研究生资产评估

接到这个让我写考研经验的请求时，往日那些痛苦的经历在几秒之内浮现在我的脑海里。为了让后面的学弟学妹不要踩我所经历过的坑，我在此写下一些过去的经历，权当铸一座引导后来人和证明自己来过的碑石。

## 一、为什么要考研？

虽然知道能看到这篇文章的大多是已经决定要考研的同学，但是**为什么要考研**仍然是一个很现实的问题。也就是说，你至少得有一个能支撑下去考研的理由。

你们学长去年在食堂里边嗦牛肉粉也在思考这个问题，直到本来打算找个实习的我看到了单位的研究生比本科生的基础工资多了一千多。没错，一千多。

那还说啥了，去考研呗。

也许你们觉得我这个理由很肤浅，但是这个肤浅的理由确实支撑了我一年的考研时光。无论是为了以后能去进优秀学府深造，或者是为了之后能有更好的平台和生存条件，多么简单的理由都能成为你去考研的理由。**有了这个核心驱动力，你就能有去考这个研究生的向往。**

## 二、考研的代价？

还有，在考研准备之前，你们也该想想代价是什么。

设想一下，你花了一年时间，费劲巴力达到了你想去的目标院校，但是你的组内压力可能会很大，研究的枯燥过程也会让你感到烦躁；亦或者你如果是跨考专业的话，专业的内容你没办法有效吸收和接受；然后三年毕业出来之后就业环境可能并没变好甚至更坏了，而你的本科同学可能已经干了三年活积累了不少经验，甚至攒了三年工资。

是不是已经开始焦虑了？但是请注意，**这些焦虑的前提，是在你考研成功的基础上**，而你可能考研还会失败。

所以在要决定考研之前，你需要想想自己的境遇与情况。如果你的实习经验丰厚或者秋招情况不错，那我还是比较建议可以去工作积累工作经验。但是如果你已经决定考研，那你必须忘掉我上一段说的所有话——毕竟你能否考上这个研，不在今朝，而在于你这一年能否坚持，能否历尽艰险而不屈，和能否有一定能考上的觉悟。**只有过了这道坎，你才能有焦虑我上一段说的话的资本，也不会后悔这一路来拼尽全力的旅程。**

## 三、设立弹性计划

很多人在考研初期都会把自己的计划表安排得满满当当，怀着雄心壮志决定自己要在一天内干完这么多事。结果具体实施起来会被一堆突发事件将自己预计的计划全部打乱，最后一天天没做完的事情积累起来，自己看着愈滚愈大的雪球心烦意乱，最后越来越懈怠，形成了极为不好的恶性循环。

**弹性计划**应对的就是这一种情况，是良方。你可以把时间尺度拉大，比如我这一周要完成哪些内容，然后再细写这一周要达到的学习目标。到了周末对自己的目标进行总结，发现自己如果有落后较大的进度就要将其标红放到下一周的计划里面。这样即使你在某一天计划被打乱的时候，你也不会过于焦虑，因为你要完成的是整个周的大目标，而不是这一天的多个小目标。列在你清单上的未完成事项越少，你的焦虑程度也会越小。

**简洁的计划，细致的执行**，这才是你考研途中必须做到的。

## 四、张弛有度

很多考研新手玩家总是会把自己的每一天安排得很紧，恨不得把已经紧绷的时间表给继续塞爆。但是考研将近三百来天的时间，真能做到每一天都能有工作吗？显然是不可能的。

与其每天都在为了疲于奔命，不如给自己**每周单独留出一天**，无论是相约小聚，抑或是自己独自放松，都是更新自己状态的不错法子。学长个人的建议是把每周的放松放在周六，这样周日你就有一整天的时间去总结这一周自己干了什么，并且为下周树立自己的新目标。

另外记得休息时间给家里打个电话。无论你处于何种处境，**家人和父母永远都是默默陪你坚持到底的最后防线**。

## 五、如何收尾

鉴于每个学弟学妹的学习情况都不同，我这里就不讲怎么进行学习的详细步骤了，来讲讲怎么在考研的最后这一两个月进行收尾和心态调整。

当年学长在最后一两个月面临所有学科累如高山的知识，精神状态几乎处于一个死人微活的状态。考完研之后再复盘一遍当时的操作，也是总结出了如何调整心态和学习策略的方法：

**首先，在总结复习阶段先把知识体系构建起来。** 经过了前面十个月甚至五个月的学习，你肯定对于知识体系有了比较具体的了解。那么这时候你应该做什么？去做思维导图。思维导图是最能够概括和细分知识大类与小类的模式图，在写的过程中你一边逐步回忆起自己所学习过的知识，构建起自己的知识体系。有了这个体系，你对于整个科目的理解也会方便许多，在最后半个月左右的知识速查也不会捉襟见肘。

**其次，把心态放平。** 学长经过了一年的图书馆学习，最后两个月整个楼层已经从之前的满满当当变成了稀稀落落，很多在考研前踌躇满志、想要整出一番大事业的考研选手因为各种原因已经离开了。但你还在这里，你依旧在坚持，希望能坚持过黑夜看到黎明。**能做到坚持到最后两个月，你已经超越至少百分之五十考研初试选手了。** 现在只需要抱着平和的心态，抛弃任何无谓的思绪，闭关静心完成总结阶段，到考场上好好发挥，就能考出自己理想的成绩。

最终之路必然艰险，但即便如此，也请你无畏冷风冻雪，超越过去的自己，成为自己的王。

## 六、结语

当学长吃着买来的点心打下结语这两个字时，过去的笑容与泪水都在回忆中浮作云烟。如今2027年考研也差不多还剩一个月了，希望各位马上奔赴考场的2027考研学弟学妹能够斩获自己理想的成绩；2028考研的学弟学妹也可以以这篇拙作作为自己的引路灯，确定好自己的方向，奔赴自己的未来。

# 美食推荐

> 本页以黄岛校区为主，汇总校内食堂、店铺与校园周边的美食。评分与评论由访客共同维护，数据保存在评论系统中。

## 怎么用

- **看分**：卡片上的蓝色星星是大家的平均分，旁边显示评分人数。
- **打分**：点击卡片下方的五角星选择分数，再点「评价」；填写昵称、邮箱后可直接提交评分，也可以写评论一并提交。
- **翻评论**：点「评价」打开详情弹窗，可以看到店铺地址、人均、推荐菜、多图和历史评论。

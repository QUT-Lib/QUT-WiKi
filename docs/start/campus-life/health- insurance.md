# 医疗保险
>本篇将介绍医疗保险的报销范围及使用流程（实际情况可能与文章内容存在出入，具体以实际为准）

## 基本信息
- 缴费：210元/年 以后可能逐年上升，可以一次交好几年，按当年价钱，如大一四年，大二三年，大三两年
- 待遇时间：首次在青参保的新生可享受自入学之日起至次年12月31日的医保待遇。
- 断保惩罚：若果没在规定时间内交钱或者中间断交，重新交钱后等三个月才能用医保，断的越久等的越久，每断一年，多等一个月，大病保险最高额度少3000
- 没病奖励：如果有一年交钱但一整年一直没用到的，大病保险最高报销额度加三千，交满四年后每多一年额度加三千
## 报销
- 日常小病去校医院报80%，无支付限额（就是不会因为你生病太多天天去看导致没钱了）
- 慢性病看定点医疗机构和病种，在社区、一、二、三级定点医疗机构，支付比例分别为 90%、90%、85%、80%；超病种限额部分，社区/一级报30%，二/三级不报。起付标准：一、二、三级机构分别为 200元、500元、800元；六家三级医院（青大附院等）为 1000元。一个年度内单独设一个起付线，部分病种（如严重精神障碍）取消起付线，部分大病（尿毒症透析等）住院与门诊慢特病只负担一个起付线。（起付标准是指花的钱到这个标准才给你报销）
- 住院：起付线，一、二、三级机构分别为 200元、500元、800元；六家三级医院 1000元。一个年度内，第一次住院按100%执行，第二次50%，第三次及以上统一 100元。报销比例：在医保支付范围内，起付线以上部分，一、二、三级机构分别报销 90%、85%、80%。
- 大病保险：超基本医保年最高支付限额以上部分：报销 85%，年度最高支付限额 40万元。基本医保报销后个人负担费用：起付线 20000元，超出部分报销 70%。其中尿毒症透析、器官移植抗排异治疗起付线降为 3000元，报销70%，年度限额 20万元。
## 报销流程
- 校医院
1. 带医保电子凭证/社保卡+校园卡去校医院挂号（普通门诊）
2. 医生问诊，开处方/治疗单/检查单
3. 收费处亮医保码或刷社保卡结算
4. 系统自动走门诊统筹，只付个人应付部分，拿小票确认“统筹支付”有数
- 转诊
1. 先到校医院挂号看诊
2. 医生判断需转外院 → 校医院开转诊备案
3. 去转诊定点医院挂号就诊、开单
4. 缴费时刷医保码/卡直结；拿结算单
- 急诊
1. 直接去定点医院急诊挂号就诊
2. 缴费时刷医保码/卡；急诊无需校医院备案
3. 能直结就直结，不能直结留票手工报
- 住院（青岛本地）
1. 入院时出示医保电子凭证/社保卡办理医保入院登记
2. 医院核验参保状态，按医保病人管理
3. 出院时联网结算，签结算单，付个人部分
- 门诊慢特病
1. 先认定：青岛医保公众号/官网/定点医院/医保站提交材料审核
2. 认定通过后，在定点机构看该病
3. 就诊刷医保码/卡直结
- 异地就医
1. 先备案：青岛医疗保障公众号→异地备案（长期/临时）；省内临时外出免备案；跨省可用国家医保平台
2. 到就医地联网定点机构，亮医保码/卡就医
3. 直接结算；未直结则留材料回青岛手工报销
- 意外伤害（无第三方）
1. 门诊：去定点医院先治疗，然后去就诊医院的专门的医保报销窗口，说明无第三方，最后申请报销
2. 住院：定点医院按无第三方意外审核后联网结算
3. 留好病历、发票、费用明细、责任说明
- 手工报销（没直结时）
1. 收齐：发票、费用明细、病历/出院记录、处方、检查报告、医保凭证、身份证、银行卡、备案/转诊记录
2. 线上：青岛医疗保障公众号→费用报销→上传材料
3. 线下：青岛医保经办大厅/工作站交材料
## 补充说明
关于大病的定义，不是按照严重程度，而是花多少钱，例：
骨折住院花3万，医保报完自付8000：没到大病起付线，不触发大病保险
白血病一年住院+门特合规自付3万：超2万部分1万 ×70% = 大病再报7000
慢特病限额查看方式
微信：关注「青岛医疗保障」公众号 → 掌办大厅 → 掌上办·我的医保 → 登录（刷脸/医保电子凭证）→ 门诊慢特病 → 选病种或搜索病种名，会显示是否限额、限额金额、申报材料 
小程序：微信搜「青岛医保」小程序 → 门诊慢特病 → 病种目录里看限额 
电脑：青岛市医疗保障局官网 http://ybj.qingdao.gov.cn → 网办大厅 → 个人登录 → 医保待遇 → 门诊慢特病/门慢门特登记

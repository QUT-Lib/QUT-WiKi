# 课程表——校历

::: info
这篇文章会介绍如何在课程表应用（多种）导入课程，并在智慧学工系统查看校历
:::

## 课程表

### WakeUp课程表

::: tip
WakeUp课程表的优点是**Android、IOS，HarmonyOS均有**，缺点是**广告繁多和导入脚本较旧**，导入后需要手动调整上课时间、开学日期、周数等信息
:::

1. 在各家应用商店下载 WakeUp 应用，打开
2. 点击右上角的⏬图标，选择“**从教务导入**”
3. 学校里搜索“青岛理工大学”，点击进入
4. 登录学校统一认证账号，进入后点击教学应用下的“**教务系统**”
5. 点击教务系统右上角的三横线按钮，选择“**选课**”下的“**个人课表查询（网页版）**”
6. 点击软件右下角的⏬按钮，等待导入完成
7. 导入完成后，点击右上角的三点按钮，选择“**课表设置**”
8. 在课表设置中，可以调整**上课时间、开学日期、周数、增删课程**等等

### 拾光课程表

::: tip
拾光课程表是一款**开源、免费、无广告**的课程表应用，导入脚本由**本站站长 LucasAndrew 亲自维护**，**开学日期、时间预设和周数准确**，目前**仅支持安卓系统**，IOS和HarmonyOS正在开发中，**支持桌面小部件**
:::

1. 进入[**拾光课程表**](https://sgschedule.jursin.top/download.html)的下载页面，选择**v8a版本**下载，安装后打开
2. 点击“我的”，下滑找到“**课表导入/导出**”，点击“**从教务系统导入**”，选择“青岛理工大学”，登录账号
3. 进入后点击右上角的三横线按钮，选择“**选课**”下的“**个人课表查询（网页版）**”
4. 点击软件右下角的“**执行导入**”按钮，等待导入完成
5. 如果需要增删课程，可以直接点击课表页面的课程区块，或者进入“**我的-高级功能-课程管理**”

### 企业微信

::: tip
企业微信优点是**无需额外下载软件**，缺点是**直接对接学校智慧学工系统，稳定性和连接速度取决于学校服务器**，并且无法显示任教老师，**无法添加小部件**在手机桌面
:::

1. 打开企业微信，点击“**D.教学-个人课表**”
2. 进入下滑即可查看

### 支付宝学生模式

::: tip
支付宝学生模式的优点是**无需额外下载软件**，缺点是**集成在支付宝内，功能杂糅且需要联网加载**，也**无法添加小部件**在手机桌面
:::

1. 打开支付宝，点击底栏“我的”，找到右上角的“**设置**”按钮
2. 进入设置后，打开“**学生模式**”，进行学信网认证
3. 返回首页，点击学校卡片中的日历，进入后**切换到中间的课表页面**
4. 在课表页面中，点击“**一键导入课表**”，选择“**从教务系统导入**”
5. 登录账号后等待跳转课表页面，点击右下角的“**识别导课**”，等待导入即可
6. 导入后也可以设置**上课时间、开学日期、周数、增删课程**等等

## 校历

校历可通过以下两种方式查看：

### 青岛理工大学融合式信息门户

1. 打开[青岛理工大学融合式信息门户](https://portal.qut.edu.cn/)，登录账号
2. 右下角即有“**校历查询**”

![青岛理工大学融合式信息门户校历](https://pic1.imgdb.cn/i/034RySdpFq5rBLLGqPT3Fx.webp)

### 青岛理工大学微信公众号

1. 打开微信，搜索并关注“**青岛理工大学**”官方公众号
2. 在公众号中，点击底部菜单的“**校历**”选项，即可查看学校校历

![青岛理工大学微信公众号校历](https://pic1.imgdb.cn/i/034RyTvXhDt3wtObE2Cgho.webp)
